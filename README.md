# ⚡ @warborn/cli

> **Official Developer Command Line Interface for the Warborn AI Operating System.**

---

## 💻 Installation

```bash
npm install -g @warborn/cli
# or execute directly
npx @warborn/cli doctor
```

---

## 🚀 Usage

```bash
$ warborn doctor
$ warborn chat "Explain multi-agent orchestration"
$ warborn agent list
$ warborn config --json
```
